# MSFILMS — Premium Photography & Cinematography Studio Flagship

Digital flagship website for **MSFILMS**, a high-end photography & wedding cinematography studio based in Saskatoon, Saskatchewan.

Designed with a modern editorial aesthetic, warm cream background system, custom fluid physics typography, mouse-following dynamic spring cursor, interactive portfolio story lightboxes, and high-performance Next.js Turbopack architecture.

---

## ✨ Features

- **Hero Entrance**: High-contrast cinematic poster with staggered word-clip animation, smooth scroll fade out, and brand ticker.
- **Brand Statement**: Editorial typography layout with signature studio photography.
- **Selected Stories Portfolio**: 3 flagship galleries (**Wedding**, **Landscape**, **Dronography**) with interactive full-screen photo story viewer (`ProjectModal`).
- **Cinematic Films**: Side-by-side poster layout with overlaid serif typography, hover video preview, and lightbox video player modal.
- **Interactive Custom Cursor**: Spring-based mouse-following cursor that dynamically morphs into dark `VIEW STORY` or `PLAY FILM` badges on hover over portfolio media. Automatically disabled on mobile/tablet screens.
- **Brand Signature Logo**: Seamless integration of `/public/logo/logo.png` with automatic white-to-black color filter switching on sticky scroll headers.
- **Services Showcase**: 6 services with smooth background image hover sweeps.
- **About Section**: Editorial dual photo layout with exact studio story and philosophy.
- **Testimonials**: 5-second auto-crossfade client review carousel.
- **Social Marquee Strip**: Infinite CSS continuous photo strip with hover pause.
- **Contact Form**: Interactive inquiry form with gold focus lines and `MM-DD-YYYY` event date field.

---

## 🛠️ Technology Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **UI & Logic**: [React 19](https://react.dev/), TypeScript
- **Styling**: Vanilla CSS Variables & [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Typography**: Playfair Display, Instrument Serif, Inter
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17 or later

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Production Build

```bash
npm run build
npm run start
```
